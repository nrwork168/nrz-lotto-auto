# Lotto Stats NRZ — เว็บสถิติหวยแยกใหม่

เว็บ Static สำหรับนำไปสร้าง GitHub Pages repository ใหม่ แยกจากเว็บเดิมได้โดยไม่ต้องแก้ไข repository เดิม

## มี 3 หัวข้อหลัก
1. **ภาพรวม** — เลขที่ออกบ่อย 2 ตัวและ 3 ตัว จากผลที่โหลดได้จริง
2. **สถิติเลข** — เลือกวิเคราะห์เลข 2, 3, 4 หรือ 6 หลัก และดูความถี่ตัวเลข 0–9
3. **ผลย้อนหลัง** — เลือกประเภทหวยและจำนวนงวด 5, 10 หรือ 20 งวด พร้อมรายละเอียดรางวัลและวันที่งวด

## วิธีสร้างเว็บไซต์ใหม่ด้วย GitHub Pages
1. ดาวน์โหลด ZIP แล้วแตกไฟล์
2. เข้า GitHub แล้วกด **New repository** เพื่อสร้าง repository ใหม่ เช่น `lotto-stats-nrz-new`
3. ตั้งเป็น **Public** (หรือเลือกตามสิทธิ์ GitHub Pages ของบัญชี) แล้วสร้าง repository
4. อัปโหลด `index.html`, `README.md` และ `.nojekyll` ที่อยู่ใน ZIP ไปไว้ที่ **root** ของ repository ใหม่ (ไม่ควรให้อยู่ในโฟลเดอร์ย่อย)
5. กด **Commit changes**
6. ไปที่ **Settings → Pages**
7. ที่ Build and deployment เลือก **Deploy from a branch** แล้วเลือก branch `main` และ folder `/ (root)` จากนั้นกด Save
8. รอ GitHub Pages deploy แล้วเปิด URL ที่ GitHub แสดงใน Settings → Pages

## แหล่งข้อมูลและข้อจำกัด
- เว็บเรียก `https://lotterychecks.com/api/public/results` จากเบราว์เซอร์โดยตรง ไม่ต้องตั้ง API key หรือ GitHub Actions
- แสดงผลจริงที่ API ส่งกลับเท่านั้น ไม่สร้างผลตัวอย่างเมื่อโหลดไม่สำเร็จ
- จำนวนงวดย้อนหลังสูงสุดต่อคำขอตามหน้าเว็บคือ 20 งวด
- ประเภทหวยในรายการเป็น slug ที่กำหนดไว้ในหน้าเว็บตามเอกสารที่ใช้จัดทำรุ่นนี้ รายการที่ API ไม่รองรับหรือไม่มีข้อมูลอาจแสดงข้อผิดพลาด/ไม่มีผล
- หวยหุ้นบางประเภทอาจยังไม่มี slug/API ที่ระบุไว้ จึงไม่ควรถือว่ารองรับครบทุกหวยหุ้น
- แหล่งข้อมูล: [LotteryChecks](https://lotterychecks.com/) · [เอกสาร API](https://lotterychecks.com/developers)
